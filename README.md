# 书刊2 AI安全工程技术路线系统架构与制度设计

> 学术·安全

## 关于本书

把AI安全当作工程问题来写：不谈科幻式失控叙事，讨论今天部署大模型系统时真实存在的风险与可落地的工程对策。技术路线（对齐训练、评测体系、推理护栏、红队与监控）、系统架构（单模型到Agent系统的安全边界与多层防御）、制度设计（评测制度化、事故报告、责任分配）三条线并进，每章从失效模式出发给出对应方案，并标注当前技术的不确定处。

## 篇目

- 导论　安全作为工程问题
- 第一章　失效模式分类学：AI 会以哪几种方式出错
- 第二章　评测科学：从 ImageNet 到危险能力评测
- 第三章　案例解剖室：十个失效案例的工程复盘
- 第四章　RLHF：人类反馈的工程化
- 第五章　宪章式对齐：Constitutional AI 与 RLAIF
- 第六章　奖励破解：对齐自身的失效模式
- 第七章　可解释性工程：打开黑箱
- 第八章　护栏架构：纵深防御的工程实现
- 第九章　越狱与提示注入：攻击面与架构级缓解
- 第十章　红队工程：从手艺到流水线
- 第十一章　发布决策：系统卡、能力评测与封控框架
- 第十二章　Agent 安全工程：权限、沙盒与供应链
- 第十三章　数据安全：记忆化、投毒与内容溯源
- 第十四章　企业 AI 治理架构：把安全变成组织能力
- 第十五章　监管的技术路线：EU AI Act 与中国双备案
- 第十六章　国际协调：从布莱切利到 AISI 网络
- 第十七章　安全工程的组织：高可靠性组织的启示
- 结语　安全即性能
- 附录　术语与缩略语速查
